# הוספת הלוגו של דובי שמיר

## איפה להוסיף את הלוגו

שים את קובץ הלוגו במיקום הבא:
```
paccool-temp-app/renderer/assets/logo.png
```

## פורמט

- **פורמט מומלץ**: PNG (עם רקע שקוף)
- **גודל מומלץ**: 512x512 פיקסל או יותר
- **שם הקובץ**: בדיוק `logo.png`

## שלבים

1. המר את קובץ ה-PDF של הלוגו לפורמט PNG
2. שנה את שם הקובץ ל-`logo.png`
3. העתק את הקובץ לתיקייה:
   `c:\Users\May\Google Drive\ai projects\demo\paccool-temp-app\renderer\assets\`

## המרת PDF ל-PNG

אופציות להמרה:
- שימוש באתר: https://www.ilovepdf.com/pdf_to_jpg
- Adobe Acrobat
- כל כלי המרה אחר שאתה מעדיף

הלוגו יופיע אוטומטית בדף ההתחברות ובמסך הסטטוס לאחר שתוסיף את הקובץ.
